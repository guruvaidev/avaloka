# User guide screenshots

Images referenced by [`../../USER_GUIDE.md`](../../USER_GUIDE.md).

**Status: all captures pending.** The previous guide's screenshots were taken
against an earlier UI and no longer match the product, so they were not carried
over — a stale screenshot is worse than none, because a reader trusts it and
then cannot find the control it shows.

Each placeholder in the guide names the file it needs and describes what the
capture should show. Capture at a viewport width of at least 1440 px, with a
dataset that has no confidential values in it — `housing.csv` is used
throughout the guide and is a good default.
