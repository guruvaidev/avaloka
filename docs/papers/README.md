# Avaloka publication plan

Working documents for the Avaloka paper programme. One file per planned paper,
plus the submission calendar and the exclusivity rules that constrain it.

| File | What it is |
| --- | --- |
| [`submission-plan.md`](submission-plan.md) | Calendar, exclusivity rules, and the order to submit in |
| [`paper-1-validation-gates.md`](paper-1-validation-gates.md) | Optimizer-aware validation gates — EDBT 2027 |
| [`paper-2-sampling-first.md`](paper-2-sampling-first.md) | Sampling-first agentic execution — PVLDB / ICDE |
| [`paper-3-system-and-lessons.md`](paper-3-system-and-lessons.md) | The system-and-lessons paper — MLSys Industry / KDD ADS |
| [`evidence-inventory.md`](evidence-inventory.md) | What is measured today, and what each paper still needs |

**Read `submission-plan.md` first.** The single most important constraint is
that the same paper cannot be under review at two archival venues at once, and
the plan is built around that rather than around deadline order.
