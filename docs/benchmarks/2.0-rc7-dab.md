# DAB re-run on `base/2.0-rc7` (616d2ee4) against the 8bd7e5d0 sweep

For review. Do not merge until the owner reads it.

Two cells of the §3.1 DAB protocol in `2.0-vs-1.0.md` were re-run on `origin/base/2.0-rc7` at `616d2ee4`.
The settings match the 8bd7e5d0 sweep (§5.1): all 54 queries, 1 trial, hints off, official per-query
validators, a $2 cap per trial, 25 iterations, 600 s per mission, and the same pricing env
(`openrouter-catalog-2026-10-17` 0.10/0.50, `groq-public-2026-10-17` 0.15/0.60). That env left out Haiku's long-prompt
tier, so the Haiku cost below is corrected (see [Cost correction](#cost-correction-2026-10-31)). Provider errors were retried exactly once
(§4, `scripts/bench/retry_infra_failures.py`). The cells ran one after the other, one benchmark process at a time.
No Gemini/Argon cells and no model-alone cells were run; the existing model-alone rows still apply.

The records are in `benchmarks/results/2.0-rc7/dab/`. Each JSON carries `git_commit 616d2ee4`, `git_dirty false`.
The logs are in `dab/logs/`.
Model-call journals and trajectories are not committed. The trajectories are already inside each JSON (§5.5 policy).

## Failure categories

Every miss gets one primary category, assigned from its evidence: the answer text, the generated SQL or code in
`tool_calls.jsonl`, the tool errors, and the validator message. Where the evidence does not decide, the miss is
marked *unknown*. The 8bd7e5d0 table is in `dab/failure-categories-8bd7e5d0.md` and the rc7 table in
`dab/failure-categories-rc7.md`, each with a one-line evidence quote per query.

| Category | Haiku 8bd7e5d0 | Haiku rc7 | gpt-oss 8bd7e5d0 | gpt-oss rc7 |
| --- | ---: | ---: | ---: | ---: |
| wrong join key or join logic | 0 | 1 | 2 | 0 |
| free-text or unstructured extraction | 5 | 7 | 7 | 6 |
| wrong output shape or format (right value, validator rejects the form) | 2 | 2 | 1 | 1 |
| wrong aggregation or filter | 7 | 4 | 5 | 5 |
| wrong table or column | 0 | 1 | 1 | 1 |
| give-up (three-strikes, tool errors, budget, timeout, declared non-answer) | 5 | 5 | 15 | 16 |
| provider error | 0 | 0 | 7 | 13 |

| other | 0 | 1 | 2 | 0 |
| unknown | 2 | 2 | 1 | 1 |
| **total misses** | 25 | 25 | 42 | 43 |

Findings that hold across both runs:

1. **The answer review false-positives on label answers.** The finding is "the question requires a numeric result but the answer contains no number".
   It fires on questions whose answer is a stage name, a BANT factor, a state code or a CPC code list.
   On Haiku it killed 4 answers in 8bd7e5d0 and 2 in rc7 (crmarenapro:3 and :9 both times).
   In 8bd7e5d0 it also pushed gpt-oss into answering `"4"` for crmarenapro:3, which passes in rc7.
   The candidate answer that was rejected is not logged anywhere.
2. **Free text is the largest reasoning failure.** Categories, sports/business/world classes and fork counts live in prose.
   Keyword classifiers miss them, or the model declares the field absent (gpt-oss DEPS_DEV_V1:2 and yelp:7 in 8bd7e5d0).
3. **Format losses with right values recur.** Examples: a markdown table that puts columns between the name and the
   value (Haiku PATENTS:3 in 8bd7e5d0); hours collapsed to weekdays (Haiku googlelocal:3, both runs); "about 33%"
   where the validator needs a decimal (Haiku GITHUB_REPOS:1 in rc7); narrow no-break spaces U+202F inside
   "Breakfast & Brunch" or "United States" (gpt-oss).
4. **Three misses are deterministic in both runs and both models:** crmarenapro:8 (tie among zero-transfer agents broken by the first id),
   crmarenapro:12 (opportunities filtered on created date in April), and music_brainz_20k:3 (revenue summed per `track_id`
   instead of per de-duplicated song). One run cannot settle whether DAB's ground truth or the agent's reading is
   right on crmarenapro:12.

## Cost correction (2026-10-31)

**Cause.** The harness priced every Haiku 5.5 call at OpenRouter's flat $0.10 / $0.50 per 1M tokens.
OpenRouter bills `anthropic/claude-haiku-5.5` at $0.50 / $2.50 per 1M for a call with 100,000 or more prompt tokens.
The DAB command's pricing env had no threshold set, so neither the per-trial cap, the run ceiling nor the reported cost saw that tier.
43 of this cell's 452 model calls had 100k+ prompt tokens.

**Real figure.** Re-priced from the cell's own logged per-call usage, the Haiku cell cost **$4.4836**, not $1.9816 (2.26×).
That is above the $3.00 ceiling this run enforced against the flat number.
The rc7 total is $7.09, not $4.59.

**No trial outcome changed.** No trial reached the $2 per-trial cap at the real price.
The most expensive was DEPS_DEV_V1:2, at $0.90 real against $0.21 reported, and it ended on the 2M-token limit, not on cost.
Pass@1, the flips and the failure categories above are unchanged.
