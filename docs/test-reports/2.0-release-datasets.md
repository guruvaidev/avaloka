## Verdict

**Not releasable as 2.0 on dataset quality. The install path is proven.**

Proven:
- On **`5ca77147`** (current `integration/2.0`): the generated public tree
  installs from its README on a clean arm64 box without `pg_config`; doctor
  passes; `analyze` runs with no API key; two corpus datasets give
  recomputable CLI findings.
- On **`0e7c9f28`**, a **pre-merge tree** 28 commits behind: CLI 19/19 ran
  (10 sensible, 8 nonsense, all D2, 1 deliberate directory refusal). The API
  never produced a sensible answer reliably: gemma 2/19 sensible; Groq
  **0/14** sensible on reading (8 vacuous, 2 nonsense, 3 refusal, 1 timeout).
  The harness classifier would have reported 5 Groq passes (H1).
- Memory: the CLI fleet peaks at **11.4 GB RAM (11,366 MiB) for a ~500 MB CSV**.
- No telemetry leak of the planted canary in any API run.

Still open, not on `integration/2.0`: **#522** (D1), **#530** (D3), **#531**
plus the deferred-profile branch (D5). D4 has no fix yet. D2 (#520) is merged
and spot-checked above but not re-measured across the corpus. The CLI and
API matrices must be re-run on `integration/2.0` after #522, #530 and #531
merge before any of these numbers describes 2.0.

Gate on `5ca77147` (`avaloka-ci-deps`, git installed, **no helm**, `CI=true`,
clean clone): `23 failed, 7665 passed, 39 skipped, 4156 deselected, 59 xfailed,
9 errors`. Fourteen of those are chart tests that fail because helm is absent,
and seven are benchmark source tests. This branch's own clone fails the same 21
(`12 failed, 7248 passed, 39 skipped, 9 errors`) and nothing else. The other 11
are failures on `integration/2.0` itself:
- C1 `test_e11_05_secret_material_absent_from_tracked_files` trips on
  `tests/contract/test_c9_public_tree_secrets.py` (#518). Its fixtures are the
  AWS documented example key and PEM headers, not real material, but C1 has
  no allow-list for them.
- `test_e2e_cli_process_help_and_version` still expects `1.6` after the 2.0.0
  bump.
- `test_a_directory_is_not_a_dataset`, `test_persona_observations_are_grounded`,
  `test_every_record_type_..._has_a_sentence`, `analysis.py ... [parquet]`,
  and five DTA auto-fetch tests ("not registered").

The release branch's gate is red independently of the dataset results.
